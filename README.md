# ATM Simulator in C

## Description
This project simulates a simple ATM machine using C programming. Users can verify their PIN, check balance, withdraw and deposit money.

## Features
- PIN verification
- Check balance
- Withdraw cash
- Deposit money
- Exit safely

## How to Run
1. Navigate to the `src` folder.
2. Compile using:
   ```bash
   gcc atm_simulator.c -o atm_simulator
